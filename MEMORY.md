Code stays for manual runs; the standard new-neighbourhood workflow is OSM + Street View only. Slojevi sections got master checkboxes; only OSM on by default.
- 2026-07-14: **parking.area retired** for `parking.run` / `parking.observation` / `parking.verdict`. The old table conflated "what a model said" (belongs to a run, append-only, many per space) with "what the human decided" (belongs to a physical space, exactly one, human-owned), which is why every new run had to overwrite the last or skip the reviewer. Observations are append-only per run_id, so Sonnet/Opus/GPT can all cover the same street and coexist; the pipeline has NO write path to parking.verdict, so a smarter model arriving later physically cannot overwrite a human decision. A consensus/merge is just another run (engine='merge') and reviews through the same path.
- 2026-07-14: The review UI reviews a **physical space, not a run** — pick a run in the "Obrada" dropdown, verdicts key on (segment_id, side) and persist across runs. Verdict records `based_on_run` so it is traceable to what was on screen.
- 2026-07-14: **segment_id is NOT a durable key** — it was `row_number() OVER ()` (no ORDER BY) in zagreb-ulice/sirine/scripts/road-width-analysis.js, so regenerating road-width-zagreb.json silently re-points every row at a different street. Now ORDER BY'd, and the export carries `osm` (OSM way) + `nm` (street name). osm_id alone is still not unique (111 ways carry 2–9 segments), so observations/verdicts carry **their own geometry** as the real anchor; `scripts/reconcile-segments.mjs` re-attaches after a road refresh by point-to-line match and REPORTS ambiguous/orphaned cases instead of guessing.
- 2026-07-14: Two silent data-loss bugs fixed. (1) The ingest wrote one row per polygon ring, so a curved street's rings collided on (segment_id, side, version) and each un-currented the one before — 18% of polygons were being discarded. geom is now MultiPolygon, one row per segment-side, rings ST_UnaryUnion'd. (2) `mixed`/`unknown` parking_manner silently mapped to the *shallowest* 2.5 m band, so every hedge under-counted area; `mixed` is now 4.0 m. Recovering both added ~11% parking area to the April corpus.
- 2026-08-02: **Coverage is now recorded separately from findings** (`parking.segment_coverage`, `parking.segment_imagery`). `parking.observation` only ever held rows where a model said parking IS present, so "analysed, found nothing" and "never looked at" were the same thing in the database — which is why citywide progress was unknowable. Coverage records every segment a run touched with outcome `parking|no_parking|failed`. The backfill recovered 254 previously-invisible correctly-empty segments.
- 2026-08-02: `process-area.mjs` never passed `--run-id`/`--area` to the ingest, so `--write` had **always** thrown — every run to date was ingested by hand. Also, the analyses filename was keyed by engine only, so a second model over the same area resume-skipped every segment and silently returned the first model's answers. Both fixed; filenames are now per (engine, model) and run_id defaults to `<area>-<model>`.
- 2026-08-02: Area selection is now a spatial join against `ppv.boundary_jms` (`parking.road_segment_mo`, 185 Zagreb mjesni odbori), ordered in concentric rings from Trg bana Jelačića. `l3_names` was unusable for this: it carries the MO *and* the gradska četvrt in one array with no marker, and spells "Donji grad"/"Donji Grad" two ways. `scripts/list-areas.mjs` prints the queue.
- 2026-08-02: Street View images are reused across areas by `capture_id` (globally unique). Processing a mjesni odbor whose četvrt was already fetched costs **0 billable requests** — verified on Ribnjak (44/44 reused). This is what makes MO-by-MO processing fit inside the 10,000/month free Street View Static tier.
- 2026-08-02: `scripts/score-run.mjs` scores runs against `parking.verdict`; `--benchmark` selects exactly the 39 segments carrying the 65 human verdicts. The scoring is only honest because coverage exists — otherwise a run that skipped a street gets credited with a correct "no parking" there. Ground truth is in **Trešnjevka-sjever (48) and Donji Grad (8), NOT Trnje (0)**.
- 2026-08-02: `gpt-5.3-codex-spark` works via codex-cli, but rejects `model_reasoning_effort="max"` (the `~/.codex/config.toml` default) — it accepts up to `xhigh`. Engine list is now claude-cli / codex-cli / openrouter / openai-batch.
